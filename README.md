- 🌐 **Interactive 3D WebGL Centerpiece**:
  - Real-time 3D models powered by **Three.js** with hardware-accelerated shaders.
  - Interactive shape switcher (**Cyber Core**, **Quantum Knot**, **Tech Gyroscope**).
  - Interactive mouse parallax and drag-to-inspect 3D physics on desktop and touchscreens.
  - 3 dynamic cyberpunk neon theme presets (Cyan, Purple, Emerald).

- 🌌 **Interactive Constellation Canvas**: Ambient 60fps particle field with connected node animations.
- 🔊 **Synthesized Web Audio Feedback**: Futuristic audio feedback for clicks and hovers generated entirely via browser Web Audio API (0 external audio files needed; toggleable anytime in the navbar).

## 🛠️ Technology Stack
- **Framework:** React 18
- **Bundler:** Vite 5
- **3D Graphics:** Three.js (WebGL 2.0)
- **Styling:** Tailwind CSS (Dark Cyberpunk & Glassmorphism design system)
- **Animations:** Framer Motion
- **Icons:** Lucide React & React Icons
- **Audio:** Web Audio API synthesizer
- **Deployment Ready:** Vercel, Netlify, GitHub Pages

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Production output will be generated cleanly in the `dist/` directory.

All personal info, skills, projects, and achievements are organized in a single clean data file:

Simply edit this file to update:

- Skills and proficiency levels
- Project descriptions and demo URLs
- Future certifications, hackathons, and awards
- Contact email and social URLs

## 🚢 Deploying to Vercel (Zero Config)

1. Push this folder to your GitHub repository at `https://github.com/ASHWINKUMAWAT360`.
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New"** > **"Project"**.
4. Select your `ashwin-portfolio` repository.
5. Framework preset will automatically detect **Vite**.
6. Click **"Deploy"** — your live 3D portfolio will be online globally in under 60 seconds!
